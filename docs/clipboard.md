# RightClick 剪贴板

参考 Paste 的公开功能独立实现；完整来源清单见 [Paste 功能调研](paste-feature-research.md)。本轮根据用户确认提供 Mac 本地功能，跨设备同步、共享和 iOS 客户端另做。

构建、测试及实机边界见 [验收记录](clipboard-verification.md)。

## 开始使用

打开控制台侧栏的 **剪贴板 → 打开剪贴板**，或右击菜单栏图标选择 **剪贴板历史**。首次默认不记录；勾选面板左下角的 **记录** 后只收集之后复制的内容。关闭窗口后继续记录，退出 RightClick 后停止。

面板采用参考 uTools 的紧凑交互：顶部直接搜索，下方用 **全部／文本／图像／文件／收藏** 切换内容，中间显示历史列表。文本分类包含文字、链接和颜色；收藏分类汇总所有已固定的记录。图片在列表内显示缩略图，记录旁显示来源、相对时间和字符数或文件数量。

单击记录会勾选或取消勾选，可连续勾选多条批量操作；顶部显示勾选数量，点击数量可全部取消。`↑`、`↓` 移动当前项，不改变已有勾选。没有勾选时，复制和粘贴作用于当前项；有勾选时，作用于已勾选的条目。双击一条记录会直接使用该条记录粘贴。

右侧操作栏放置复制、粘贴、快速预览和收藏。**更多（…）** 收纳编辑、纯文本复制、图片旋转、删除记录、固定板管理与顺序粘贴；顶部 **筛选** 可按固定板、内容类型、来源应用和日期进一步查找。设置、保持窗口打开和清空未收藏历史也在右侧栏。默认切换到其他应用时面板收起，可用图钉按钮保持打开。

| 操作 | 默认快捷键／入口 |
| --- | --- |
| 显示／隐藏历史 | `⌥⌘V` |
| 搜索 | 直接输入，或 `⌘F` |
| 切换分类 | `←`、`→` 循环切换；搜索框为空或列表获得焦点时生效 |
| 移动当前项 | `↑`、`↓` |
| 勾选／取消勾选 | 单击记录；顶部数量按钮取消全部勾选 |
| 粘贴当前项或已勾选内容 | Return；`⇧Return` 使用纯文本 |
| 粘贴单条记录 | 双击该条记录 |
| 粘贴前九个可见条目 | `⌘1`–`⌘9`，同时按 Shift 使用纯文本 |
| 快速预览 | 列表获得焦点后按空格，或右侧眼睛按钮 |
| 新建片段 | `⌘N` |
| 关闭面板 | Escape |
| 开始／结束顺序粘贴 | `⇧⌘C` |
| 粘贴队列下一条 | `⇧⌘B` |

三个全局快捷键可在剪贴板设置中录制、清除或恢复默认。快捷键冲突会在面板显示提示；仍可从菜单栏使用。

历史面板打开后，空搜索框中的 `←`、`→` 会在全部、文本、图像、文件、收藏间循环切换，搜索焦点保留。搜索框已有文字时，左右键仍用于移动光标；列表获得焦点后，左右键可带着当前搜索条件切换分类。组合方向键保留原有编辑行为。

在搜索框使用中文输入法组字、选择候选词时，Return、方向键和 Escape 先交给输入法处理，不会触发历史粘贴、移动当前记录或关闭面板。确认输入完成后，再单独按一次 Return 才粘贴当前项或已勾选内容。

记录支持文字、链接、富文本、图片、PDF 图像表示、颜色和多个文件。原始剪贴板格式会单独保存；纯文本操作去除格式。历史按最近复制时间排列，重复内容移动到前面，保留收藏关系。可搜索正文、标签、来源和图片中的文字，并叠加类型、应用、日期、固定板筛选。

多选文字以换行合并并保留可恢复的富文本格式；多选文件保留多个文件地址。可以拖入内容、拖出记录、新建文字模板、编辑文字及标签、旋转位图。列表空格可打开系统快速预览；链接需从“更多”或右键菜单选择 **预览链接（联网）** 后才在独立窗口加载。固定板支持新建、重命名、删除、颜色、板顺序、板内条目顺序和批量固定；一个记录可以加入多个固定板。

文件记录保存**原文件地址**，不是文件备份。文件移动或删除后，历史仍可搜索，但再次复制文件会提示不可用。删除历史不会删除原文件。

## 直接粘贴与顺序粘贴

直接粘贴会先恢复剪贴板，再回到之前使用的应用发送粘贴快捷键。需在系统设置中授予 RightClick **辅助功能** 权限；未授权时仍可复制，再手动切回目标应用按 `⌘V`。

顺序粘贴需先启用记录并授予辅助功能权限。按 `⇧⌘C` 开始，逐条复制；内容按收集顺序加入队列，再用 `⌘V` 或 `⇧⌘B` 依次粘贴。面板显示剩余数量，菜单栏提供反转及结束操作。重复复制同一条内容也会再次入队。队列只在本次会话存在。

普通 `⌘V` 通过系统事件监听串行派发，给接收应用留出读取当前剪贴板的时间。应用没有统一的“粘贴已完成”回执：自定义粘贴行为、远程桌面、异常延迟或系统权限变化仍需在目标应用核对。复制监视采用轮询和应用切换事件；快于轮询的多次复制可能无法逐条捕获。未采集的新剪贴板内容优先保留，不用旧队列覆盖。

## 保留与隐私

- 默认保留 **30 天**；设置为 `0` 永久保留。固定记录不受期限和“清空历史”影响。删除固定板会解除该分类，不删除其他固定板里的引用；解除最后一处固定后重新适用历史期限。
- 数据位于 `~/Library/Application Support/RustClick/clipboard/`，目录权限 0700，文件权限 0600。元数据原子写入，二进制附件独立保存；损坏索引会保留并报告错误，不自动覆盖。单条采集上限 32 MB。
- 支持暂停、定时暂停、排除应用 Bundle ID 和正文正则表达式。应用标记的机密、临时、自动生成内容会跳过。来源由前台应用推断，系统不提供可信的复制来源审计；浏览器内密码扩展等未标记的内容可能仍被记录。
- 正则规则对可读正文在采集时生效；图片文字由本机 Vision 异步识别，匹配后删除记录。**图片可能已先落盘**，因此涉及敏感图像应暂停采集或排除来源应用。OCR 可能失败或误识别，首次识别可能较慢。新增排除规则不回溯清理旧记录；删除历史或撤销 MCP 权限也不会收回 AI 客户端已取得的副本。
- 窗口捕获保护使用 macOS 的窗口共享设置，只对兼容捕获方式生效，不能保证所有录屏软件或新版系统都隐藏内容。共享整个屏幕前，请关闭剪贴板及其编辑／预览窗口。
- 本地存储不是独立加密保险库；同一系统用户及其获准程序可能读取数据。

## 本地 MCP

在 **剪贴板设置** 中打开 **允许本机 AI 工具通过 MCP 读取固定板**，再将本应用可执行文件配置为 MCP stdio 服务。默认仅暴露实际固定在收藏板中的内容；读取普通历史需另外勾选。取消勾选后，下一个请求立即按新权限检查。

示例（将 `command` 改成实际安装位置的绝对路径）：

```json
{
  "mcpServers": {
    "rightclick-clipboard": {
      "command": "/Applications/RightClick.app/Contents/MacOS/RightClick",
      "args": ["--clipboard-mcp"]
    }
  }
}
```

通过构建脚本 `--install` 安装的路径是 `/Users/你的用户名/Applications/RightClick.app/Contents/MacOS/RightClick`。本地构建可使用仓库 `dist/RightClick.app/Contents/MacOS/RightClick` 的绝对路径。协议握手兼容 `2025-06-18`、`2025-03-26`、`2024-11-05`。

| 工具 | 用途 |
| --- | --- |
| `clipboard_search` | 在已授权范围内搜索文字、OCR 和元数据 |
| `clipboard_get` | 按 ID 读取已授权条目的文字和元数据 |
| `clipboard_pinboards` | 列出本地收藏板 |

这是**只读 stdio** 接口：由本机客户端启动子进程，不监听网络端口，不提供 HTTP/OAuth、修改收藏或读取文件实际内容的工具。它信任你选择的本机客户端，不能代替每个 AI 客户端的权限隔离。剪贴板文字属于不可信输入，工具不会把其中的指令当系统指令。

历史采集与 OCR 在本机处理；主动预览链接会联网访问该地址。获准的 AI 客户端可能将返回的内容发送给自己的模型服务。是否开启以及是否开放全部历史应由你选择。

## 本轮边界

使用 RightClick 自己的原生紧凑列表，交互参考 uTools；详情通过快速预览、编辑或链接预览按需打开。尚未提供 Paste 的 MCP 写入工具、逐客户端 OAuth 授权及基于屏幕上下文的智能推荐。标准 AppKit 文字编辑区域可由兼容系统提供写作工具，本机 macOS 14 不具备 Apple Intelligence，未验证其行为。没有导入 Paste 私有数据库，也没有连接 iCloud。直接粘贴和顺序粘贴的实际验收结果以验收记录为准。
