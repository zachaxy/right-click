# RightClick v0.1.0

RightClick 首次发布：一个本地运行的 macOS 访达右键工具箱。全部功能免费，无需账号、订阅或激活码，源码采用 MIT 许可。

## 主要功能

- 新建 Markdown、TXT、Office 文档和代码文件，支持导入自定义模板。
- 文件复制、移动、剪切粘贴、重命名、隐藏与目录整理。
- 在当前目录打开终端、iTerm2、VS Code 等应用。
- 图片格式转换、Mac/iOS 图标集生成及自定义文件夹图标。
- ZIP/7z 压缩解压，以及 AES-256 加密归档。
- 文件哈希校验、目录空间统计、离线二维码与乱码文件名修复。
- 自定义右键菜单一级、二级、三级位置，支持分组继承和单项调整。
- 菜单栏常驻，提供中文操作台和独立操作窗口。

## 下载与安装

适用于 Apple Silicon（M 系列）Mac，要求 macOS 14 Sonoma 或更高版本。不提供 Intel、Windows 或 Linux 安装包。

1. 下载 `RightClick-0.1.0-arm64.dmg`，将 `RightClick.app` 拖入镜像中的 Applications 文件夹；也可下载 ZIP 后解压安装。
2. 打开 RightClick，在系统设置中启用 **RightClick Finder** 访达扩展。应用的“通用设置”提供入口。
3. RightClick 显示在顶部菜单栏，不显示在 Dock；单击菜单栏图标打开控制台，右键可退出。
4. 若需完全磁盘访问权限，在对应系统设置页点击“＋”，选择实际安装的 `RightClick.app` 并启用。应用中的“前往授权”仅打开系统设置，需要手动添加应用。

此版本采用本地 ad-hoc 签名，尚未经过 Developer ID 签名或 Apple 公证。首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”。

附件中的 `.sha256` 文件提供 DMG 和 ZIP 的 SHA-256 校验值。应用包含运行依赖，无需另行安装 Rust、Swift、Node、Python 或 Homebrew。

## 已验证与已知限制

- 本次发行构建通过架构、最低系统版本、动态库依赖及签名检查。
- DMG 已只读挂载验证，应用内容与构建产物一致；ZIP 解压后内容比对通过。
- 从挂载的安装包运行文件新建、加密 ZIP/7z 压缩与解压往返检查通过。
- 外接磁盘、AirDrop、自动化、截图等功能依赖设备与系统权限，未逐一验证所有设备及权限组合。
- Pages、Numbers、Keynote、WPS 原生格式需要导入用户自己的模板。
- 没有云账号同步；配置和模板保存在本机 `~/Library/Application Support/RustClick/`。
- 应用包附带本项目及依赖许可证、7-Zip 26.03 对应源码与构建说明。
